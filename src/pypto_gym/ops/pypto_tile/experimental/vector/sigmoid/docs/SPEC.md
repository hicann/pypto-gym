## 算子需求规范

### 1. 基础信息
- **算子名称**: Sigmoid
- **算子分类**: element-wise  <!-- element-wise / reduction / matmul / attention / custom -->

### 1.1 功能描述

对输入张量逐元素应用 Sigmoid 激活函数，将任意实数映射到 (0, 1) 区间。属于经典激活函数，常用于神经网络的输出层（二分类概率）或门控机制。

### 1.2 算法参数

无

### 1.3 数学公式

$$
\text{Sigmoid}(x) = \sigma(x) = \frac{1}{1 + e^{-x}}
$$

逐元素公式: `out[b, d] = 1 / (1 + exp(-x[b, d]))`
