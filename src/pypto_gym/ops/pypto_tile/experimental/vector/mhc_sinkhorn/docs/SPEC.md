# mhc_sinkhorn 算子规格文档

## 1. 算子基本信息

- **算子名称**: `mhc_sinkhorn`
- **算子类型**: 数学计算算子
- **功能概述**: Sinkhorn-Knopp 双随机矩阵迭代归一化算法
- **应用场景**: MHC (Manifold-Constrained Hyper-Connections) 系统中的残差连接矩阵约束

## 2. 算子语义

`mhc_sinkhorn` 实现 **Sinkhorn-Knopp 双随机矩阵迭代归一化算法**，用于将矩阵通过交替行列归一化迭代转换为双随机矩阵。

**双随机矩阵定义**:
- 每行元素之和 = 1
- 每列元素之和 = 1
- 所有元素为正数

**算法原理**:
通过交替对矩阵进行行归一化和列归一化，迭代收敛到双随机矩阵。该算法在最优传输、矩阵平衡等领域有广泛应用，在 MHC 系统中用于确保流间混合权重矩阵满足双随机性约束。

## 4. Shape 范围与约束

### 4.1 动态轴与静态轴

| 轴名称 | 标记 | 典型取值范围 | 说明 |
|--------|------|--------------|------|
| `B*S` | DYNAMIC | {8, 64, 1024, 2048, 4096} | 批大小 × 序列长度，动态轴，无需重编译 |
| `N` | STATIC | 4 或 8 | 矩阵维度，静态轴，变化会触发重编译 |

### 4.2 Shape 约束条件

1. **矩阵维度对称**: 输入必须为 `[B*S, N, N]` 方阵
2. **动态轴限制**: `B*S` 支持 8 ~ 4096 范围内的动态变化
3. **静态轴约束**: 当前实现使用 `N = 4`，算法支持任意 N 值但需重编译
4. **最小 Shape**: `[8, 4, 4]`
5. **最大 Shape**: `[4096, 8, 8]`（理论支持，实际测试至 `[4096, 4, 4]`）

## 5. 计算逻辑

### 5.1 数学公式

**Step 1: 初始行归一化（Softmax）**
```
h_comb = softmax(x, dim=-1) + eps
```

**Step 2: 初始列归一化**
```
col_sum = sum(h_comb, dim=-2, keepdim=True)
h_comb = h_comb / (col_sum + eps)
```

**Step 3: 交替归一化（迭代 num_iters-1 次）**
```
for _ in range(num_iters - 1):
    # 行归一化
    row_sum = sum(h_comb, dim=-1, keepdim=True)
    h_comb = h_comb / (row_sum + eps)
    
    # 列归一化
    col_sum = sum(h_comb, dim=-2, keepdim=True)
    h_comb = h_comb / (col_sum + eps)
```

### 5.2 计算流程图

```
输入 x [B*S, N, N]
  ↓
Step 1: softmax(dim=-1) + eps  （行归一化初始）
  ↓
Step 2: 列归一化 (sum dim=-2 + eps)
  ↓
Step 3: 循环 num_iters-1 次
  ├─ 行归一化 (sum dim=-1 + eps)
  └─ 列归一化 (sum dim=-2 + eps)
  ↓
输出 [B*S, N, N] (双随机矩阵)
```

## 6. 精度要求

### 6.1 精度类型

- **输入精度**: FP32
- **输出精度**: FP32
- **计算精度**: FP32（全程保持）

### 6.2 精度约束

1. **全程 FP32**: 输入、输出、中间计算均为 FP32
2. **Softmax 约束**: PyPTO softmax 操作仅支持 FP32
3. **数值稳定性**: 所有除法操作添加 `eps` 防止除零
4. **收敛性保证**: 默认迭代 20 次，输出矩阵行列和误差 < 1e-3

### 6.3 容差标准

- **相对容差 (RTOL)**: 0.0078125 (1/128)
- **绝对容差 (ATOL)**: 0.0001
- **双随机性质容差**: 行列和误差 < 1e-3
